# VisibleFix Market Research

Interactive marimo notebook for VisibleFix market analysis.

## Quick Start

```bash
# Run the notebook
marimo edit docs/research/market/research_notebook.py

# Or use the script
./docs/research/market/run.sh
```

The notebook opens at `http://localhost:2718`

## Files

| File | Description |
|------|-------------|
| `research_notebook.py` | Interactive marimo notebook ✅ Working |
| `research_notebook.md` | Markdown backup |
| `market_analysis_report.md` | Print-ready report |
| `run.sh` | Launch script |

## Notebook Content (11 Cells)

1. **Intro** - Project context
2. **Cities** - Target city data (8 cities)
3. **Pricing** - Municipality pricing tiers
4. **Competitors** - 8 competitive solutions
5. **Pain Points** - Problem/solution matrix
6. **City Ranking** - Prioritized list (İzmir 8.0)
7. **Behavior** - Citizen substitute analysis
8. **Funding** - SDG 11 sources
9. **Findings** - Key insights
10. **Recommendations** - Strategic advice
11. **Sources** - Data references

## Requirements

- Python 3.11+
- marimo >= 0.22.0
- pandas >= 2.0.0

Install: `pip install marimo pandas`
